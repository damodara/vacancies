# Программа для работы с вакансиями

Курсовая работа по объектно-ориентированному программированию. Программа для получения информации о вакансиях с платформы HeadHunter, сохранения их в файл и удобной работы с ними.

## Описание

Программа предоставляет возможность:
- Поиска вакансий на HeadHunter по ключевым словам
- Сохранения вакансий в JSON и CSV форматах
- Фильтрации вакансий по различным критериям
- Сортировки вакансий по зарплате
- Получения статистики по вакансиям
- Удобного консольного интерфейса

## Установка и запуск

1. Убедитесь, что у вас установлен Python 3.12 или выше
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите программу:
   ```bash
   python main.py
   ```

## Использование

После запуска программы вы увидите меню с опциями:

1. **Поиск вакансий на HeadHunter** - введите ключевое слово для поиска
2. **Показать топ N вакансий по зарплате** - укажите количество вакансий
3. **Фильтр вакансий по ключевому слову** - поиск среди сохраненных вакансий
4. **Фильтр вакансий по диапазону зарплат** - фильтрация по зарплате
5. **Показать все сохраненные вакансии** - просмотр всех вакансий
6. **Показать статистику по вакансиям** - статистика по сохраненным вакансиям
7. **Очистить все сохраненные вакансии** - удаление всех данных
8. **Экспорт в CSV** - экспорт данных в CSV формат

## Архитектура

### Принципы ООП

- **Наследование**: Абстрактные классы `VacancyAPI` и `FileSaver` с конкретными реализациями
- **Инкапсуляция**: Приватные методы и свойства в классах
- **Полиморфизм**: Единый интерфейс для работы с разными форматами файлов

### Принципы SOLID

- **Single Responsibility**: Каждый класс отвечает за одну задачу
- **Open/Closed**: Легко добавлять новые форматы файлов и API
- **Liskov Substitution**: Подклассы могут заменять базовые классы
- **Interface Segregation**: Интерфейсы разделены по функциональности
- **Dependency Inversion**: Зависимость от абстракций, а не от конкретных реализаций

## API HeadHunter

Программа использует официальное API HeadHunter:
- Базовый URL: `https://api.hh.ru/vacancies`
- Поддерживается поиск по ключевым словам
- Получение до 20 страниц результатов
- Обработка ошибок подключения

## Форматы данных

### JSON
Стандартный формат для сохранения вакансий с полной информацией.

### CSV
Альтернативный формат для экспорта данных в табличном виде.
